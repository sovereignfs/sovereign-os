Garnet direction · stone neutrals + deep garnet accent · proposal

Color

Two primitive scales — stone (neutrals) and garnet (accent) — mapped by a semantic layer that is the only thing changing between light and dark. Because the accent is itself a red, error-solid stays a bright pure red and must never be darkened toward garnet; status is always icon + text, never color alone (per the Console health brief).

Garnet vs. danger — the managed adjacency

Unavailable Healthy

The brand accent (deep, desaturated wine) and the danger semantic (bright pure red) share a family on purpose but never a value range. Rules: danger fills use error-solid only; destructive actions always carry an icon or explicit verb; no garnet fill may exceed garnet500's saturation on an interactive control.

Typography

Hanken Grotesk (body) · JetBrains Mono (code) — fallback stacks apply when web fonts are not loaded. OS gives mono an elevated role: machine facts render in mono, human sentences in Hanken. Versions, IPs, checksums, release identifiers, and capability ids are machine facts.

Mark

The family grammar: the spark (the assistant) inside each product's own trust boundary. Sovereign OS's boundary is the machine itself — a rounded silicon square, the spark in the core. The glyph doubles in-UI as the capability-receipt icon: the closed square marks what stayed on the device; an outward arrow marks what left the home network.

Console screens

The Console is a static, no-build web page shipped in the appliance image — every asset local, both schemes, flat surfaces (the current gradient and backdrop blur are dropped). Health reflects the shipped read-only console restyled. Chat previews milestone 01.2's local-vs-internet disclosure and capability-receipt pattern only — the voice input/output and Home Assistant device control shown alongside it are longer-term assistant vision, not 01.2 scope: voice is explicit 01.2 non-scope and Home Assistant mutation is deferred to the confirmation-gated vertical slice that follows 01.2 (see docs/roadmap/01-2-local-conversation-capabilities.md §7 and §11).
